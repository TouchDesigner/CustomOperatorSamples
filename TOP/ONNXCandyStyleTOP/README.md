# ONNX Candy Style TOP
This example implements loading an ONNX based AI model using the [ONNX Runtime](https://onnxruntime.ai). It uses CUDA to execute the model.

## Prerequisites
* Requires the ONNX Runtime and a TouchDesigner build that ships the matching `onnxruntime.dll`. See [Installing the ONNX Runtime](../../README.md#installing-the-onnx-runtime-windows-only) for the versions and where to put it.
* Requires an Nvidia GPU of the Turing generation (GeForce GTX 16 / RTX 20 series) or newer. Currently this example uses CUDA as the execution engine. This example could be changed to use a different engine.
* Requires a CUDA 13 Toolkit to be [installed](../../README.md#installing-the-cuda-toolkit-windows-only).
* It requires the __candy.onnx__ model, which is available on the [ONNX Examples Github](https://github.com/microsoft/onnxruntime-inference-examples/tree/main/c_cxx/fns_candy_style_transfer). The model is directly available [here](https://raw.githubusercontent.com/microsoft/Windows-Machine-Learning/master/Samples/FNSCandyStyleTransfer/UWP/cs/Assets/candy.onnx).
  * Place __candy.onnx__ next to the .dll generated by this project that you load into the CPlusPlus TOP (or your Plugins directory where you place the .dll).

This TOP takes one input which must be 8 bit RGBA, 720x270 resolution.
